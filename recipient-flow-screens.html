Implementation Key Technical Decisions

State Machine
Hierarchical: ExperiencePhase → ChapterIndex → GiftSubScreen. Each screen is a component, orchestrator routes to the right one via AnimatePresence.
Transitions
All screen transitions use Motion's AnimatePresence mode="wait". Slide left/right for chapters. Fade for acts. Scale for gift opening.
Confetti
canvas-confetti library with emoji shapes via shapeFromText(). Preset functions for each occasion. Hardware-accelerated canvas rendering.
Mini-Games
Spin wheel: custom SVG + Motion useSpring for realistic deceleration. Lucky draw: CSS 3D flip with perspective transforms. Both configurable by creator.
Gate Interactions
4 lock variants built with CSS 3D transforms + Motion drag gestures. Ribbon cut uses useDragControls. Each has satisfying unlock animation.
Reward Tickets
Canvas API renders styled ticket with item, name, date, branding. Converts to JPG via toDataURL(). Download triggered via anchor element.
